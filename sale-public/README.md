# خانه‌ی مهر — نسخه‌ی نمایشی و قابل فروش

نسخه‌ای مستقل از بازی برای ضبط محتوا، معرفی محصول و سفارشی‌سازی برای مشتری.
نسخه‌ی شخصی اصلی در `index.html` و `public/` باقی مانده است؛ خروجی فروش از آن‌ها استفاده نمی‌کند.

## اجرای نسخه‌ی فروش

```bash
npm ci
npm run dev:sale -- --port 5173
```

در پیش‌نمایش Arena، مسیر `/` و `/sale/` نسخه‌ی کامل و `/sale/guest/` بازدید کوتاه را باز می‌کنند.
در خروجی انتشار، این مسیرها `/` و `/guest/` هستند.

## ساخت و انتشار

برای انتشار کنار نسخه‌ی شخصی روی GitHub Pages:

```bash
npm run build
```

این دستور هر چهار صفحه را می‌سازد و workflow فعلی GitHub Pages همان پوشه‌ی `dist/` را منتشر می‌کند:

- `https://rwinfu.github.io/NANA/` — نسخه‌ی شخصی
- `https://rwinfu.github.io/NANA/guest/` — بازدید کوتاه شخصی
- `https://rwinfu.github.io/NANA/sale/` — نسخه‌ی فروش
- `https://rwinfu.github.io/NANA/sale/guest/` — بازدید کوتاه فروش

برای ساخت نسخه‌ی فروش به‌تنهایی:

```bash
npm run build:sale
npm run preview:sale -- --port 4173
```

پوشه‌ی `dist-sale/` یک سایت مستقل است. محتویات آن را در ریشه‌ی هاست استاتیک یا یک پوشه‌ی دلخواه منتشر کن.
برای انتشار در زیرپوشه‌ی GitHub Pages، فایل `base: './'` در `vite.sale.config.js` مسیرها را نسبی نگه می‌دارد.
هیچ بک‌اند، حساب کاربری یا درگاه پرداختی به بازی اضافه نشده است؛ این نسخه محصول/دموی قابل ارائه است.

فایل `mehr-house-sale.zip` همان خروجی استاتیک را برای تحویل یا آپلود روی هاست دارد.

## چه چیزهایی عوض شده‌اند؟

- نام محصول: **خانه‌ی مهر**؛ تابلوی سه‌بعدی: **MEHR HOUSE**.
- شخصیت‌های خیالی بزرگسال: **نیکا و سامان**.
- نامه، عنوان‌ها، توضیح قاب‌ها، پیام‌ها و نام گربه‌ها دوباره نوشته شده‌اند.
- ۱۰ تصویر مولد هوش مصنوعی، بدون استفاده از عکس شخصی به‌عنوان مرجع؛ ۱۷ قاب دیگر برش/پردازش هنری همان تصاویرند.
- هر ۲۷ قاب بازی پر است: ۱۸ قاب راهرو و ۹ قاب اتاق.
- ویدیوی شخصی حذف و با پرتره‌ی متحرک بی‌صدا از تصاویر همین نسخه جایگزین شده است.
- آهنگ شخصی حذف و با ملودی تولیدشده توسط Web Audio جایگزین شده است.
- عکس گربه‌های شخصی با پرتره‌های بریده‌شده از تصاویر خیالی جایگزین شده‌اند: **میشا و فندق**.
- حافظه‌ی مرورگر کلید جدا دارد؛ نام‌ها یا تنظیمات ذخیره‌شده‌ی نسخه‌ی شخصی به این نسخه منتقل نمی‌شوند.
- قلعه، ماجراجویی نجات، گالری، اتاق ویدیو، نامه‌ی سه‌بعدی، هدیه، گل‌فروشی، رقص، کارت پستال و کنترل موبایل حفظ شده‌اند.

## شخصی‌سازی برای مشتری

فایل اصلی محتوا `src/sale-content.js` است:

- `defaults`: نام فرستنده/گیرنده، پیام پلاک و رنگ لباس.
- `letterParagraphs`: متن نامه؛ ترتیب پاراگراف‌ها حفظ می‌شود.
- `memories` و `soloMemories`: عنوان، توضیح و مسیر عکس قاب‌ها.
- `edition`: برند، پیام پروانه، عنوان کارت پستال، موسیقی و مشخصات ظاهری شخصیت‌ها.

عکس‌ها در `sale-public/sale/memories/` هستند. برای حفظ چیدمان، ۱۸ عضو `memories` و ۹ عضو `soloMemories` را نگه دار.
اگر نام یا متن پیش‌فرض را عوض کردی، `edition.storageKey` را هم یک نسخه جلو ببر تا مقدار قدیمی مرورگر جای متن تازه را نگیرد.
متن‌های ثابت صفحه در `sale.html` و `sale-guest.html` هستند.

تابلوی سردر را می‌توان دوباره ساخت:

```bash
node tools/make-sign.mjs 'YOUR HOUSE' src/sale-sign-outline.js
```

برای بازتولید برش‌ها و ویدیو، اسکریپت `tools/sale-media/prepare_assets.py` فقط پوشه‌ی `sale-public/` را می‌خواند.
نیازمندی‌های اختیاری آن `Pillow` و `imageio-ffmpeg` هستند. تصاویر منبع مولد هوش مصنوعی از قبل در مخزن موجودند.

## بررسی جداسازی و آزمون

```bash
npm test
npm run build:sale
npm run check:sale
```

ساخت فروش فقط `sale-public/` را کپی می‌کند و ماژول محتوای شخصی را با محتوای فروش جایگزین می‌کند.
`check:sale` خروجی واقعی را برای نام‌ها، مسیرهای رسانه‌ی شخصی، کلید حافظه‌ی قدیمی و نشان هوش مصنوعی بررسی می‌کند.
این بررسی جای بازبینی حقوقی/حریم خصوصی را نمی‌گیرد؛ هنگام انتشار، مخزن شخصی یا پوشه‌ی `public/` را آپلود نکن.

آزمون‌ها: ۲۱۶ آزمون موفق. بررسی مرورگری: بارش هر ۲۷ قاب، ورق‌زدن گالری، ساخت کارت پستال، نامه، ورود کامل و بازدید کوتاه، بدون خطای JavaScript یا درخواست ناموفق. خروجی انتشار نیز در مرورگر بررسی شد: هر ۲۸ تصویر/پوستر پاسخ موفق گرفتند، کارت پستال ساخته شد و نامه و ورود کامل کار کردند.

## حقوق و شفافیت

تصاویر، اشخاص و رابطه‌ی این نسخه خیالی‌اند و در صفحه‌ی شروع و راهنما با همین عنوان معرفی شده‌اند.
هیچ عکس واقعی از صاحب پروژه یا پارتنرش در ساخت تصاویر استفاده نشده است.
موسیقی نسخه‌ی فروش، ملودی ساده‌ی تولیدشده در کد است و فایل آهنگ شخصی را درخواست نمی‌کند.
کد و کتابخانه‌های شخص ثالث تابع مجوزهای خودشان هستند (`three` و Vite: MIT؛ فونت‌های Vazirmatn، Lalezar و Baloo 2: OFL).
پیش از فروش، شرایط پلتفرم انتشار و سرویس تولید تصویر و نیازهای حقوقی بازار مقصد را بررسی کن. این فایل ادعای مجوز انحصاری یا تضمین حقوقی برای تصاویر مولد هوش مصنوعی ندارد.
