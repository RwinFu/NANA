# خانه‌ی ما — Our Home

یک بازی سه‌بعدی قابل‌بازی در مرورگر: از حیاط جلویی به خانه وارد شو، با آواتارهای low-poly در فضای گرم خانه قدم بزن و ۱۲ عکس خاطره را در قاب‌ها ببین.

۱۲ عکس پوشه‌ی `Nana` در Google Drive به نسخه‌های محلیِ بهینه‌شده تبدیل شده‌اند؛ اصل عکس‌ها در Drive دست‌نخورده‌اند. داده‌های دوربین از نسخه‌های وب حذف شده است.

## کنترل‌ها

- **کامپیوتر:** با `W A S D` یا کلیدهای جهت‌نما حرکت کن؛ `E` یا دکمه‌ی پایین برای ورود و دیدن خاطره‌هاست. با کشیدن ماوس دوربین را بچرخان و با چرخ ماوس فاصله‌ی دوربین را تنظیم کن.
- **گوشی و تبلت:** جوی‌استیک مجازی برای حرکت و کشیدن صحنه با انگشت برای چرخاندن دوربین. دکمه‌ی پایین اگر از در یا قاب‌ها دور باشی، خودکار به سمت در یا نزدیک‌ترین قاب می‌رود؛ نزدیک که شدی دوباره آن را بزن. در صورت نیاز، با زدن دوباره‌ی دکمه حرکت خودکار را متوقف کن.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی قابل‌انتشار:

```bash
npm run build
```

خروجی وب در `dist/` ساخته می‌شود. فایل `our-home-deploy.zip` نیز بسته‌ی آماده‌ی انتشار همان خروجی است.

## انتشار روی GitHub Pages

تنظیمات انتشار خودکار در `.github/workflows/deploy.yml` آماده است و مسیرهای نسبی طوری تنظیم شده‌اند که به نام مخزن وابسته نباشند:

1. یک repository بساز و فایل‌های پروژه را روی شاخه‌ی `main` قرار بده.
2. در GitHub برو به **Settings → Pages** و گزینه‌ی **GitHub Actions** را به‌عنوان روش انتشار انتخاب کن.
3. پس از اتمام workflow در زبانه‌ی **Actions**، آدرس سایت به شکل `https://USERNAME.github.io/REPOSITORY/` خواهد بود.

عکس‌ها در `public/memories/` همراه پروژه هستند؛ اگر سایت در دسترس عموم باشد، فایل عکس‌ها هم با آن قابل‌دسترسی خواهد بود.

## عکس‌ها و خاطره‌ها

عکس‌ها در `public/memories/` هستند. ترتیب، عنوان و توضیح هر عکس در `src/memories.js` تنظیم شده است. برای جایگزینی یا افزودن عکس:

1. فایل تصویر را در `public/memories/` قرار دهید.
2. در `src/memories.js` مقدار `imageSrc` خاطره را با helper همان فایل، مثلاً `memoryImage('new-photo.jpg')` تنظیم کنید تا مسیر روی GitHub Pages هم درست بماند.
3. برای خاطره‌ی جدید، یک شیء با `id`, `title`, `caption`, `date`, `imageSrc` و `palette` اضافه کنید.

نام فرستنده، گیرنده و پیام پلاک در صفحه‌ی شروع قابل‌تغییرند و در مرورگر ذخیره می‌شوند.
