# خانه‌ی ما — اولین سالگرد

یک خانه‌ی سه‌بعدی و قابل‌گشت در مرورگر. تو به‌عنوان پرنسس از حیاط وارد خانه می‌شوی، راهروی خاطره‌ها را قدم می‌زنی، دوازده عکس را از نزدیک می‌بینی و در انتهای راهرو یک پاکت نامه‌ی بزرگ منتظرت است.

## قابلیت‌ها

- **حیاط و راهرو:** خانه با پلاک سردر (متن از تنظیمات تو)، راهروی طولانی با دوازده قاب روشن و نور فانوس‌های آویزان.
- **قاب‌های خاطره:** با نزدیک شدن به هر قاب و زدن `E` (یا کلیک روی قاب) عکس بزرگ، عنوان و توضیح آن را ببین. با کلیدهای جهت‌نما بین خاطره‌ها جابه‌جا شو.
- **دوستت دارم:** هر بار که دکمه را بزنی، قلبی بالا می‌رود و شمارنده بالا می‌آید. عدد در مرورگر ذخیره می‌شود.
- **ویدیوی اتاق:** با نزدیک شدن به قاب ویدیو و زدن `E` (یا کلیک/تپ روی خود صفحه) ویدیو در پنجره‌ی بزرگ
  پخش می‌شود. ویدیو کلاً صدا ندارد؛ فقط تصویر است.
- **پاکت نامه:** در انتهای راهرو، جلوی پنجره‌ی قلب، یک پاکت نامه‌ی بزرگ ایستاده است. با `E` (یا کلیک روی آن) سرپوشش باز می‌شود، نامه بیرون می‌آید و بعد متن نامه با نام فرستنده و گیرنده نمایش داده می‌شود.
- **جشن سالگرد:** از دکمه‌ی «جشن سالگرد» در بالای صفحه، پیام سالگرد، آمار و آتش‌بازی را ببین.
- **نامه و کارت پستال:** نامه‌ی متنی، و عکس یادگاری از نمای فعلی که به صورت کارت پستال قابل دانلود است.
- **موسیقی:** یک لوپ پیانوی ساده که با دکمه‌ی موسیقی خاموش یا روشن می‌شود.

## کنترل‌ها

- **کامپیوتر:** `W A S D` یا کلیدهای جهت‌نما برای حرکت، `Shift` برای دویدن، `E` برای تعامل، کشیدن ماوس برای چرخش دوربین، چرخ ماوس برای نزدیک و دور شدن، `H` برای راهنما، `Esc` برای بستن پنجره‌ها.
- **گوشی و تبلت:** جوی‌استیک گوشه‌ی پایین برای حرکت، کشیدن صفحه برای چرخش دوربین، دو انگشت برای بزرگ‌نمایی، و دکمه‌ی `E` روی صفحه برای تعامل.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه‌ی قابل انتشار:

```bash
npm run build
npm run preview
```

خروجی در `dist/` ساخته می‌شود.

## ویدیوی اتاق

ویدیوی اتاق روی یک قاب طلایی در انتهای راهروی عکس‌ها پخش می‌شود. برای اینکه روی گوشی گیر نکند:

- فایل `public/memories/solo-video.mp4` نسخه‌ی وب است: H.264 (Main)، ۷۲۰×۱۲۸۰، ۳۰ فریم بر ثانیه،
  **بدون هیچ ترک صوتی**، با `faststart` (فهرست فایل اول می‌آید تا پخش قبل از پایان دانلود شروع شود)
  و حدود ۱ مگابایت. صدا از فایل اصلی حذف شده و بازی هم چیزی برای پخش صدا ندارد.
- تصویر کوچک قبل از شروع پخش: `public/memories/solo-video-poster.jpg`.
- پنجره‌ی بزرگ هم همان فایل بی‌صدا را پخش می‌کند؛ در کل بازی هیچ صدایی از ویدیو پخش نمی‌شود.
- در بازی، ویدیو فقط وقتی پخش می‌شود که کاراکترها نزدیک قاب باشند و دوربین آن را ببیند؛ از دور متوقف می‌ماند
  تا حافظه و پردازنده برای خود بازی بماند. اگر کیفیت تصویر بازی پایین بیاید (روی گوشی ضعیف)، بازی
  خودش رزولوشن رندر را کم می‌کند تا ویدیو روان بماند.
- با نزدیک شدن به قاب و زدن `E` (یا کلیک/تپ روی خود صفحه) ویدیو در یک پنجره‌ی بزرگ و بی‌صدا باز می‌شود.
- اگر ویدیو را عوض کردی، همین تنظیم‌ها را نگه دار. نمونه‌ی تبدیل با ffmpeg:

```bash
ffmpeg -i input.mp4 -an -vf "fps=30,scale=720:-2:flags=lanczos" \
  -c:v libx264 -profile:v main -level 3.1 -pix_fmt yuv420p \
  -crf 25 -maxrate 1200k -bufsize 2400k -preset slower \
  -g 30 -keyint_min 15 -sc_threshold 40 -movflags +faststart \
  public/memories/solo-video.mp4

ffmpeg -ss 0.3 -i public/memories/solo-video.mp4 -frames:v 1 -vf scale=480:-2 -q:v 4 \
  public/memories/solo-video-poster.jpg
```

## عکس‌ها و متن‌ها

- عکس‌ها در `public/memories/` هستند (`memory-01.jpg` تا `memory-12.jpg`).
- عنوان، توضیح، بخش (chapter) و رنگ قاب هر خاطره در `src/memories.js` است. پیام‌های پیش‌فرض، متن نامه (`letterParagraphs`) و متن‌های سالگرد هم همان‌جا هستند.
- برای تغییر ترتیب یا افزودن قاب، آرایه‌ی `memories` را ویرایش کن. (چیدمان راهرو تا ۱۲ قاب طراحی شده است.)
- نام‌ها، پلاک، پیام سالگرد، تعداد «دوستت دارم» و رنگ لباس از صفحه‌ی شروع قابل تغییرند و در مرورگر ذخیره می‌شوند.

## انتشار روی GitHub Pages

فایل `.github/workflows/deploy.yml` آماده است. مسیرها نسبی هستند، پس به نام مخزن وابسته نیستند:

1. فایل‌ها را روی شاخه‌ی `main` قرار بده.
2. در **Settings → Pages** گزینه‌ی **GitHub Actions** را انتخاب کن.
3. بعد از پایان workflow، سایت در آدرس `https://USERNAME.github.io/REPOSITORY/` باز می‌شود.
